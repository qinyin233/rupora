## 检查中处理的问题

- 源码视图遗漏了新的页面布局参数，导致编译失败：已接入共享页面布局。
- 大纲条目使用按钮的默认居中方式，层级缩进不明显：改为左对齐。
- 短状态文字在剩余空间中居中：明确左对齐，同时保留溢出省略。
- Page Up/Down 仍按旧的固定页边距估算光标位置：改为读取共享页面宽度。
- 分栏右侧原有横向分隔控件额外占据高度：改为在两栏之间绘制竖线，统一两侧页面起点。
- 更多菜单继承旧横向布局，被撑到约 600 pt：改为 248 pt 内容宽并限制高度，子菜单同样支持滚动。
- 行内代码新增围栏会与原文相邻反引号融合，二次切换误删原文：将紧邻反引号纳入代码内容，并覆盖转义和代码块上下文。已有长围栏取消后再添加可以规范化围栏长度；属性测试分别检查新增格式的完整往返和取消格式的内容保留。

系统文件对话框的自动化窗口定位曾返回 `no monitor found for window` / `coordinate input geometry is unavailable`。重连 Computer Use 后恢复正常应用操作；测试文稿通过应用支持的启动参数加载，并实际验证了从最近文件重开。该工具异常不作为应用缺陷。
