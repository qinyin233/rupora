# RUPORA 2：P1–P6 完成情况

RUPORA 2 已完成从 WebView/Vditor 外壳到原生 Rust 编辑器的六个优先级阶段。这里的“完成”
指每项均已有实现、回归测试或自动化门禁，不代表软件从此不再演进。

## P1：生产力编辑

- 智能列表、引用、任务与有序列表续行，空列表退出。
- 成对符号、选区包裹、URL 智能粘贴、Tab 缩进与 Unicode 安全选择。
- 可配置快捷键、命令面板、查找替换、折叠、同步滚动。
- 剪贴板图片、附件复制、会话光标与滚动位置恢复。
- 多文档、工作区、大纲、最近文件、拖放和本地链接。

## P2：文件可靠性与安全

- 编码/换行往返、同目录原子保存、失败回滚和 64 MiB 文档上限。
- 外部文件监控、三方合并、差异查看、移动文件重新关联。
- 文档锁与单实例应用协调，避免静默覆盖。
- 带版本、校验和、上限及损坏隔离的恢复快照。
- HTML 清理、生成内容上限和工作区本地路径边界。

## P3：原生富 Markdown 与导出

- GFM、YAML front matter、唯一 Unicode 锚点、目录、脚注和交叉引用。
- 纯 Rust 数学公式 SVG 与 Mermaid 图表渲染，不调用浏览器。
- 可视化表格单元格编辑与对齐。
- 原生 HTML、PDF 导出和系统打印入口。

## P4：性能与质量

- 块索引消除逐块全文回扫，2 万块增量协调保持线性热路径。
- Criterion 基准与可执行的大文档性能预算。
- 单元测试、Proptest 属性测试、保存故障注入。
- Markdown 与表格双 fuzz 目标，定时 nightly 构建。
- 严格 Clippy、三平台 CI、RustSec 与 cargo-deny 门禁。

## P5：桌面产品化

- Windows、Linux、macOS Markdown/文本文件关联。
- 单实例启动；第二次启动将文件安全转交给现有窗口并请求聚焦。
- 编辑器右键菜单、键盘导航以及 egui/AccessKit 辅助功能树。
- 后台 HTTPS 更新检查；稳定版与预发布版使用各自更新通道。
- 轮转诊断日志与 panic 回溯，界面可直接打开日志目录。
- 发布产物包含 SHA-256、CycloneDX SBOM 与 GitHub 构建来源证明。
- macOS 签名/公证和 Windows Authenticode 的密钥入口；未配置密钥时仍明确标记为开发包。
- 第三方 GitHub Actions 固定到不可变提交。

## P6：纯 Rust 收口与大文档交互

- 删除 Vue、Vditor、Tauri、Node 清单和双重 Cargo 工程；跨平台图标迁入独立资源目录。
- 持久状态/命令与数学、Mermaid、SVG 缓存从窗口编排模块中分离。
- 编辑缓冲区只在第一次真实修改时惰性捕获旧正文，空闲帧不再克隆整篇文档。
- 输入期间延迟全量 Markdown 派生分析，120 ms 空闲后合并刷新；混合模式按需立即刷新。
- 排版文本字符到 Markdown UTF-8 源码的边界映射，支持混合模式块内点击定位。
- 单元、属性、Clippy 与大文档性能门禁覆盖以上热路径。

## P7–P8 仍需完成

下一阶段集中在真实桌面交互与发布/扩展边界：

- P7：可重放 GUI 场景、输入法组合、辅助功能语义与 HTML/PDF 导出视觉回归。
- P8：签名更新清单、架构感知发布产物，以及隔离的扩展服务协议。

这些能力会继续遵守“默认构建不引入 WebView”的边界。
