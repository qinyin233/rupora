## 复现后修复

| 问题 | 修复后的行为 |
| --- | --- |
| 三段文档选择前两段，绘制未选第三段时整数下溢 | 非相交范围不会计算负的无符号偏移；debug 回归不再 panic |
| Ctrl+A 与文字同帧，使用旧光标配对或吞掉段落分隔符 | 先建立正确选区，再顺序处理输入；同帧和分帧行为一致 |
| 跨段选区按方向键后输入仍删除旧选区 | 文档层先折叠或定位选区，再让目标块处理后续文字 |
| 同帧提交中文并启动下一次组合，取消后丢失已提交文字 | 已提交部分进入文档历史；仅当前预编辑内容留在 IME 会话 |
| 写作模式 Ctrl+Home/End 以及 Shift 组合只操作当前块 | 导航或选择到文档首尾，保留方向和选区锚点 |
| 代码边界方向/删除键与文字同帧，输入落在错误块 | 先处理跨代码边界导航，再应用同帧文字 |
| 输入后同帧按 Undo，撤销先于输入执行 | 帧末的历史命令在本帧编辑记录完成后执行 |
| 删除代码后的整段正文，再输入会接到闭围栏上 | 围栏后的空白位置归入后续正文编辑范围，保留独立段落 |
| 源码与写作模式之间切换，光标在旧视口外 | 双向定位实际光标；写作模式在虚拟块高度更新期间继续跟随到可见位置 |
| 表格字段含奇数反斜杠加管道符，列错位并丢掉后一列 | 根据转义奇偶性序列化；0–5 个反斜杠矩阵保留行内语义和后列 |
| 引用式链接、图片在独立块中显示为原始语法 | 两种画布、活动投影、图片识别、链接命中共用全文引用定义；保留原文偏移 |
| 连续 Ctrl+A 始终只能选当前块 | 第一次选块，再次全选文档；状态栏说明这一行为 |
| PageUp/PageDown 困在短段落中 | 使用段落排版位置进行跨块翻页，并保持内容不变 |

引用定义缓存随块索引更新，避免每次绘制重新解析全文；Unicode 引用标签使用与 Markdown 解析器一致的大小写折叠。

## 回归范围

新增 **26 项**自动回归：16 项输入/导航/删除测试，10 项文档/保存/表格/引用测试。输入回归实际运行 egui Context、TextEdit、键盘/IME 事件与绘制裁剪检查。文档测试覆盖磁盘保存、跨标签选区与撤销、外部修改保护、恢复合并和冲突、表格删除、脚注显示等正常对照。

原有“替换选中的分隔符”测试改为明确选择分隔符：Ctrl+Shift+End 的产品行为已变为选择到全文末尾，不能再将其用作选择当前块末尾分隔符的测试工具。该保护断言保留，全文选择另有四组回归。
