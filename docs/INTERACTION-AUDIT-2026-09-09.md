# 原生窗口交互回归记录

日期：2026-09-09。环境：Windows、Rust 1.93.1，运行本地 Release 版本。
本记录补充此前的源码审计和代码块修复，记录本轮模拟日常写作时新发现的问题。

## 本轮确认并修复的四个问题

| 实际操作 | 修复前表现 | 原因与修复 |
| --- | --- | --- |
| 在空白文档输入三个反引号和 `python`，按 Enter，再输入代码 | 代码进入语言信息字符串，例如 `pythonprint(...)` | 未闭合围栏提前进入代码块分支，却跳过 Enter 补全；同时编辑范围排除了末尾换行。恢复围栏补全，只对完整闭合的代码块隔离外部段落间距。 |
| 点击正在编辑的任务列表中的复选框 | 只移动光标，任务状态不变 | 活动编辑器只处理了修饰键点击链接。增加投影坐标到任务标记的映射，将勾选作为可撤销的文档编辑。 |
| 在正文和代码中输入 `🙂` | 显示缺字方框 | Windows 字体回退未包含 emoji 字体。为正文和等宽字体增加系统 Segoe UI Emoji 回退；当前窗口显示为单色字形。 |
| 编辑一个段落，按 Ctrl+A，再输入替换文本；后面紧接任务列表 | 段落间隔被一并替换，后面的任务项并入正文 | 块编辑缓冲区含有供空行导航使用的分隔符。块内全选现在限制在该块内容范围内，保留下一个块的分隔符。Ctrl+A 仍是当前编辑块的全选。 |

以上四项均先在真实窗口复现，再用回归测试确认修复前失败、修复后通过。
实现和测试位于 [app.rs](../native/src/app.rs)。

## 实际窗口操作覆盖

- 从空白文档依次输入标题、中英文、数字、emoji、任务列表和带语言的代码块，使用真实 Enter、方向键和快捷键事件。
- 点击活动任务框，检查状态变化和撤销恢复。
- 在两个段落之间拖动选区，复制、粘贴、撤销、重做，核对源码。
- 全选替换当前段落，确认后面的任务列表仍为独立块，随后撤销。
- 点击代码块的复制按钮，将多行代码粘贴进新建代码块，再输入中文注释；保存后检查语言、代码正文和结束围栏。
- 双击代码块下方新建正文并输入文字；保存后的 Markdown 确认正文位于结束围栏之外。
- 点击表格数值 `123`，按 End 并输入 `4`，确认得到 `1234`；撤销恢复原值。
- 点击行内代码字符之间并输入 `X`，确认得到 `inlineX_code` 且格式保留；撤销恢复。
- 切换写作、源码、分栏、阅读视图，核对代码、任务列表、表格和行内格式。
- 保存综合测试文档，与测试前的文件进行 SHA-256 比较，确认所有临时编辑撤销后内容完全恢复。

用户原有测试草稿保留；本轮输入在独立测试文档中进行。
本地复现文档保存在被 Git 忽略的 `target/manual-*-20260909.md`，修复不依赖这些文件。
