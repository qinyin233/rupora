# 跳转与极端删除交互回归

日期：2026-09-10。Windows 原生窗口，延续前一轮修复；独立测试文档未覆盖用户草稿。

## 新确认的故障

1. **代码块前连续 Delete**：在普通段落末尾，第一次删除空行，继续 Delete 会把开头围栏拼接到正文末尾。原来的结束围栏变成新的开头，后续正文、任务列表和表格全部被解释成代码。
2. **代码块后连续 Backspace**：在后续正文行首退格，删光空行后会把正文拼到结束围栏上，使结束围栏失效，后续内容被吞入代码块。
3. **选区删除或替换绕过边界**：在代码块前按 End、Ctrl+Shift+End 选中块间空白，再 Delete，会产生第一种损坏。回归测试同时覆盖 Cut 和 Paste 替换这段空白的情况。

这三条操作路径属于同一类围栏结构保护缺失。真实窗口和保存后的源码均已确认，相关自动测试在修复前失败。

## 修复

- 保留围栏前后必需的一条换行；多余空行仍可删除。到达结构边界时，Delete/Backspace 移动光标进入代码正文，不改动围栏。
- 非空代码块第一行开头退格时，光标移至前一块末尾，继续输入不会损坏开头围栏。
- 当前块的删除、剪切、粘贴或输入覆盖选区后，确保后面的围栏仍从独立一行开始。
- 显式跨块选择整个代码块后删除仍然有效；清空代码正文后继续退格仍可移除空代码块。

实现和四项新增回归测试位于 [app.rs](../native/src/app.rs)。测试断言文档源码、边界跳转后的光标，以及撤销恢复结果。

## 实际窗口操作

- 全选多行代码、Backspace 清空、再次 Backspace 移除空块、分步撤销恢复。
- 从下往上跨越格式段落、任务列表、正文和代码块拖选，按 Delete；随后点击表格再撤销，恢复被删除内容。
- 从后面的格式段落跳到代码块之前，连续 Delete；从代码内部跳到后续正文，连续 Backspace。
- 反向拖选行内代码后切换为整段全选，再删除包含粗体和行内代码的整个段落。
- 在清空位置输入组合 emoji、组合重音、中英文和密集 Markdown 符号，再继续输入；保存核对原始 Unicode 字符和 Markdown。
- 在段落末尾用 Ctrl+Shift+End 选择块间空白并删除。
- 多行代码 Tab/Shift+Tab、Ctrl+X/Ctrl+V；核对缩进还原、剪切后空块和粘贴后的完整代码正文。
- 新 Release 窗口复测连续 Delete、连续 Backspace、代码开头退格和选区删除；围栏与后续正文均保持完整，保存的源码只减少了可删除的空行。
- 在源码视图全选整篇并删除，切到写作视图撤销，再重做、撤销；保存后 SHA-256 与整篇清空前一致。

复现样本和过程日志保存在被 Git 忽略的 `target/extreme-*.md`、`target/extreme-*.log`。
