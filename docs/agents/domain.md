# Domain documentation

This repository uses a single context. Before exploring code, read root
`CONTEXT.md`, `docs/ARCHITECTURE.md`, and relevant decisions in `docs/adr/` when
present. If an optional document does not exist, continue without creating a
placeholder. Record an ADR when an actual architectural decision is resolved.

Use the vocabulary defined in `CONTEXT.md`, especially document identity,
document revision, snapshots, external changes, blocks and rendering dependencies.
Explain conflicts with an existing ADR instead of silently overriding it.
